## 🟢 技能与面试风向

### 📊 行业趋势
- **Java 仍是后端第一大语言**，国内 Java 岗位占比 ~45%，但初级岗同比萎缩 20-23%，纯 CRUD 岗位降幅达 30-45%
- **"Java+AI+云原生"复合技能人才** 薪资逆势上涨 20-50%
- **Python 岗位增长**集中于 AI/ML 赛道，传统 Python 后端（Django/Flask）岗位增速放缓
- 2026 年 AI 岗位量同比增长 **8.7 倍**，具身智能岗位暴增 **15 倍**
- 新经济行业平均月薪 **49,608 元**，同比 +12.13%
- **DeepSeek 完成首次外部融资**，募资超 500 亿元，估值突破 3380 亿元 — AI 赛道持续火热
- **智谱 GLM-5 发布**，字节、阿里、腾讯、美团、百度全部宣布接入

### 🎯 面试风向变化
1. **大厂笔试题型已变天**：不再是纯 LeetCode，新增系统设计选择题、代码纠错重构、业务场景分析（如秒杀系统流量峰值分析）
2. **面试更侧重工程落地能力**：面试官从八股转向项目深挖——"你的代码如何证明有效？测试覆盖率多少？QPS 怎么评估？"
3. **AI 技能成为硬性要求**：Spring AI、LangChain4j、RAG、MCP、Agent 成为 Java 后端面试高频考点
4. **OpenJDK 封杀 AI 生成代码**：2026 年 4 月新规，AI 辅助提交需审慎
5. **前程无忧报告**：31 岁+求职者占比升至 53.91%，经验价值重新回归，企业更倾向"复合型即战力"

### 📚 推荐学习路径（来自最新面经）
- **Java 方向**：Spring Boot → 微服务 → JVM 调优 → 高并发 → Spring AI/LangChain4j → RAG/Agent/MCP
- **Python 方向**：Python 基础 → FastAPI/Django → PyTorch → LLM Fine-tuning → Agent/RAG
- **必学**：Golang 作为第二语言越来越受欢迎（AI 基建主流语言）
