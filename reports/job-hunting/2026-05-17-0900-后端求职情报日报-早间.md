## 🟢 技能与面试风向

### 🔥 2026年5月大厂Java面试高频考点（CSDN多篇面经交叉验证）

**必考题一：Spring Boot 核心**
- 自动配置原理（@Conditional 系列注解）
- Starter 依赖机制
- HikariCP 连接池优势
- Spring Security 认证授权流程

**必考题二：微服务架构**
- 服务注册与发现（Eureka/Nacos）
- Kafka 消息队列原理与使用场景
- Spring Cloud 组件全家桶
- 分布式事务解决方案

**必考题三：JVM 深度**
- 内存模型（堆/方法区/虚拟机栈/本地方法栈/程序计数器）
- 垃圾回收机制：G1/ZGC 调优实战
- 类加载机制与双亲委派

**必考题四：Spring 设计模式**
- 单例（Bean 默认 Scope）
- 工厂（BeanFactory/ApplicationContext）
- 代理（AOP 实现）
- 模板方法（JdbcTemplate/RestTemplate）
- 观察者（ApplicationEvent）

**必考题五：数据库 ACID**
- MySQL 事务 ACID 底层实现（Undo Log/MVCC/Redo Log WAL）
- 隔离级别与锁机制
