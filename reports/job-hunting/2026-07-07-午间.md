## 🟢 技能与面试风向

### 1. Java技能要求变化（"存量稳固，结构洗牌"）
- Java仍占国内后端岗位**45%以上**，但初级岗位总量同比下降**20-23%**
- 初级CRUD岗位萎缩最明显（降幅**30-45%**），AI编程工具已替代70%样板代码
- **供需比**：初级15:1，中级10:1，高级/架构师5:1
- **复合技能溢价**："Java+AI+云原生"人才薪资逆势上涨**20-50%**
- 热门框架：Spring Boot 3.x、Spring AI、LangChain4j、Spring Cloud

## 💡 今日求职建议（3句话总结）

1. **提前批窗口仅剩30天，必须立刻行动**：字节、腾讯、阿里、美团等大厂提前批7月全面启动，录取率是正式批的2-3倍（字节提前批15% vs 正式批5%），现在就是投递的黄金窗口。建议优先投递**测试开发岗**作为"捡漏"策略，竞争烈度更低。

2. **Java仍是第一选择，但必须升级技能栈**：纯CRUD型Java岗位正在被AI替代，面试核心考察点已转向JVM调优、高并发设计、分布式系统、云原生部署。**建议：Spring Boot/Cloud + Redis + K8s + 至少一个AI框架（Spring AI/LangChain4j）**，复合技能溢价可达20-50%。

3. **Python后端双栈趋势明显，量化/AI方向值得关注**：Python+Java双栈岗位增多，量化开发薪资50-80K·24薪领跑全场。AI全栈和大模型应用开发是Python新增长点，建议学习FastAPI/Django + LLM API + RAG技术栈，兼顾远程工作机会。
