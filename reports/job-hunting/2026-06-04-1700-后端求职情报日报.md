## 🟢 技能与面试风向

### 📝 2026 面试新趋势

> **"八股文已经救不了你了"** — 2026 后端面试核心变化

1. **不再考 HashMap 原理，而是问系统设计**
   - "你们系统 QPS 峰值多少？突然涨十倍，服务会挂在哪里？"
   - 需要能讲清楚：容量规划、限流降级、扩容方案

2. **AI Coding 工具成标配**
   - Cursor、Copilot、WindSurf 使用能力是基本要求
   - 面试会问："你如何用 AI 将开发效率提升 3 倍？"
   - OPPO 实习面经已出现："你是如何使用 AI 进行 coding 的？"

3. **Java 技术栈升级重点**
   - Java 21 虚拟线程（Project Loom）— 并发模型革命
   - GraalVM 原生编译 — 毫秒级启动，适配 Serverless
   - Spring Boot 3.x + Spring Cloud Alibaba 微服务体系
   - Spring Boot + MyBatis-Plus 仍占 76% 企业采用率

4. **全栈压力增大**
   - 后端需懂基本前端 + K8s/云原生 + 数据分析
   - 企业倾向用更少的人完成更多事

5. **Python 方向新机遇**
   - Python 大模型 Agent 开发成热门
   - 微服务（FastAPI/Flask/Django）+ AI 集成

### 📚 高频面试题 TOP 领域
- Java 多线程与虚拟线程
- Spring 全家桶（IOC/AOP/Spring Boot 自动配置）
- Redis 缓存策略与集群
- MySQL 索引优化与分库分表
- 分布式事务（Seata）、服务注册发现（Nacos）
- 消息队列（Kafka/RabbitMQ）
- JVM 调优与 GC 策略
- 系统设计（高并发/高可用/秒杀）
