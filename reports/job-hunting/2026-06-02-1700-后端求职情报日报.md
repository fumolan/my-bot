## 🟢 技能与面试风向

### 🔥 技术栈风向标

1. **Spring Boot 4.0 正式发布**（基于 Spring Framework 7.0）：
   - 内置弹性架构：`@Retryable`、`@CircuitBreaker`、`@RateLimiter` 开箱即用
   - 虚拟线程（Virtual Threads）全面启用
   - GraalVM 原生镜像正式化
   - Spring AI 原生 Agent 支持
   - 内置声明式 REST 客户端，减少 70% HTTP 层代码
   - 来源：[腾讯云](https://cloud.tencent.com/developer/article/2680391) | 可信度：⭐⭐⭐ 官方

2. **Spring Cloud 2026**：微服务架构进入"自治化"阶段，Gateway 4.0 + 云原生生产级落地。
   - 来源：[chenxutan.com](https://www.chenxutan.com/d/3016.html) | 可信度：⭐ 社区讨论

3. **2026 大厂面试新增必考项**：
   - RAG 系统架构设计（向量数据库选型、混合检索、文档切片）
   - AI Agent 工具调用（异构 tool_calls 统一处理）
   - 大模型 API 集成与 Prompt 工程
   - 分布式系统设计 + AI 能力嵌入
   - 来源：[CSDN](https://blog.csdn.net/m0_73692704/article/details/161458535) | 可信度：⭐ 社区讨论

4. **AI 面试工具兴起**：鹅来面（OfferGoose）等 AI 模拟面试平台，支持全真语音交互 + 基于 JD 定制面试。
   - 来源：[博客园](https://www.cnblogs.com/nut-king/p/20254584) | 可信度：⭐ 社区讨论

## 💡 今日求职建议

1. **纯 Java 后端已不够，AI 能力是标配**：字节/阿里/蚂蚁 2026 招聘明确要求"传统研发基础 + AI 大模型/Agent 技术栈"。建议立即补齐 RAG、Agent 架构、大模型 API 集成三项技能，这比再刷 100 道 LeetCode 更有性价比。

2. **Spring Boot 4.0 是今年面试分水岭**：内置弹性架构、虚拟线程、声明式 REST 客户端都是高频考点。如果你简历上还写"熟悉 Spring Boot 2.x"，面试官可能直接跳过。
