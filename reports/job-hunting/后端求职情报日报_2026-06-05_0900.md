## 💡 今日求职建议

1. **AI Agent 是当前最强简历杠杆**：今天多个热招岗位都提到 LangChain/LangGraph 经验，即使你主攻 Java 后端，也建议至少做一个 AI Agent 相关的 Side Project 放简历上。南京白利度科技甚至提供 Remote 的 AI 外企岗位，值得重点关注。

2. **大厂在"边裁边招"**：阿里、腾讯、美团都在结构调整，但字节跳动已启动 27 届校招（350-500 元/天），华为云核心网也在招 26 届。投递策略：避开正在裁员的业务线（腾讯文档、美团产品），瞄准 AI 基础设施和云服务方向。

3. **Spring Boot 3.x + 微服务 + K8s 是安全牌**：薪资数据表明，具备微服务架构设计能力（Spring Cloud Alibaba/Seata/Nacos）的 Java 后端，在深圳/杭州/北京都能拿到 15-30K 以上。建议系统补充容器化和分布式事务实战经验。
