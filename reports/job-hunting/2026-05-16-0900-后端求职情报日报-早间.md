## 🟢 技能与面试风向

### 🔥 2026年5月最新：27道AI Agent大厂面试真题发布

字节、快手、腾讯、Shopee真实考过的27道AI Agent面试题已整理公开，核心考点：

**Agent基础概念（必考）：**
- LLM Agent 定义 vs 单次调用的差异（闭环决策 vs 开环生成）
- 没有外部工具还能叫Agent吗？（弱环境Agent概念）
- Agent 的记忆系统分类：短期/长期/工作记忆

**核心架构与框架（高频）：**
- **ReAct 框架**原理（Thought → Action → Observation 循环）
- **RAG 原理与实现**：检索增强生成的完整 Pipeline
- **Function Calling 机制**：LLM 如何调用外部工具和 API
- **MCP 协议**：Model Context Protocol，AI与外部系统的通信标准
- **Multi-Agent 协作**：多智能体之间的任务分配与通信

**Java 技术栈 AI 面试（京东健康真题）：**
- 一面（技术深度）：Spring AI / LangChain4j 使用经验、RAG Pipeline 设计
- 二面（系统设计）：高并发 AI 服务架构、向量数据库选型
- 三面（产品视野）：智能分诊、健康管理、用药依从性场景设计

📎 来源：[腾讯云](https://cloud.tencent.com/developer/article/2668240) / [CSDN](https://blog.csdn.net/weixin_43726381/article/details/161098993) | 可信度：⭐ 大厂真题+社区整理
