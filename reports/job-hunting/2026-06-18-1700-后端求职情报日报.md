## 🟢 技能与面试风向

### 📋 面试趋势
1. **Java 基础仍是核心**：多数公司后端面试仍以 Java 基础 + 数据库操作为主，分布式锁/Spring源码深挖并非普遍要求
2. **Spring Boot 2.x→3.x 迁移是热题**：45%+ 生产项目仍跑在 2.x，2026年12月31日 EOL，升级经验成加分项
3. **Java 21 虚拟线程**：Project Loom 正式 GA，成为新的面试高频考点
4. **AI 能力成标配**：单纯 Java 后端已不够，企业期望候选人具备 AI 集成能力（Spring AI 2.0 已 GA）
5. **面试优先级排序**：项目经历深挖 → Java核心/MySQL/Redis → 框架应用 → 系统设计 → 分布式/高并发 → JVM

### 🛠 技术风向标
- **Spring AI 2.0 GA 发布**：Spring 生态 AI 集成能力里程碑
- **飞算 JavaAI**：30 秒智能生成 Spring Boot 3.x 脚手架
- **Trusted RAG**：Spring Boot 构建可验证、可引用的企业 RAG 系统成新方向
- **大模型系统化学习路线**：Python基础→深度学习→LLM原理→工程实战，3-6个月

## 💡 今日求职建议

1. **抓住暑期实习末班车**：联通（6/25截止）、农行、度小满等还在招，暑期实习是秋招拿 return offer 的最佳路径。美团转正率据称接近 100%，优先投递有明确转正通道的岗位。

2. **Java 后端必须叠加 AI 技能**：2026 年纯 CRUD 已无竞争力。至少掌握 Spring AI 集成、RAG 系统搭建、LLM API 调用。面试中能聊"如何用 AI 提升后端开发效率"会显著加分。

3. **大厂 AI 岗需求爆发但门槛分化**：百度 90% 实习岗位与 AI 相关，但 AIGC 应用岗不要求算法背景。如果算法基础薄弱，优先投"AI 应用开发/Agent 开发"而非"算法工程师"，后者竞争极度激烈且偏爱硕博。
