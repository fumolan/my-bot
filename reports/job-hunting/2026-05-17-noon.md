## 🟢 技能与面试风向

### 一、Spring Boot 高频面试考点（大厂标配）
1. **@SpringBootApplication** = @SpringBootConfiguration + @ComponentScan + @EnableAutoConfiguration 三层解构
2. **自动配置原理**：@Conditional 系列注解，根据 classpath 依赖自动装配
3. **@Transactional 事务**：AOP 动态代理实现，默认 RuntimeException 才回滚，自调用失效
4. **HikariCP 连接池**：高性能、开箱即用
5. **Spring Security**：过滤器链 + 安全上下文

### 二、微服务架构必问
- 服务注册与发现：Eureka / Nacos
- 消息队列：Kafka（Topic/Producer/Consumer 模式）
- 网关：Spring Cloud Gateway
- 熔断降级：Sentinel / Resilience4j
- 容器化：Docker 打包部署

### 三、JVM 调优与内存模型
- 内存结构：堆、方法区、虚拟机栈、本地方法栈、程序计数器
- GC 回收器：Serial / Parallel Scavenge / CMS / G1 / ZGC
- 回收算法：标记-清除、标记-整理、复制算法、分代收集

### 四、校招面试逆袭要点（来自真实案例）
- 不能只刷 Demo 项目，面试官会质疑「没有业务逻辑」

- 竞赛经历（蓝桥杯等）写在简历上能显著增加面试机会
- 系统学习 > 零散刷视频

### 五、行业趋势
- AI 编码工具对软件行业中期影响分析（2026-2030）成为热门话题
- Python 技术栈持续活跃：Django + AJAX、SQL CRUD、PyOhio 2026 征稿
- 开源生态加速：DeepSeek 等中国 AI 模型能力仅落后美国 6-8 个月
