## 🟢 技能与面试风向

### 面试趋势：八股文已死，项目为王

**2026面试三大变化**：

1. **问法全变**：同一道题，2022年背八股文能过，2026年追问底层原理→追问真实项目经验→追问AI结合场景 [^15]
2. **三个必考方向**：
   - 你在项目里具体做了什么、遇到什么坑、怎么解决
   - 你用AI工具（Cursor/Copilot/GPT）做了什么辅助开发
   - 你是否做过Agent/RAG相关项目 [^16]
3. **AIGC作品集成关键筹码**：有RAG知识库/AI测试平台等作品集的候选人，Offer总包比纯背八股文的**高出一倍** [^17]

### Java仍必备 — 但要求升级

Java面试核心考察点（2026版）：
- JVM内存结构、GC调优、类加载机制
- 多线程与高并发（线程池、JUC、Disruptor）
- Spring Boot自动配置原理、Spring Cloud微服务体系
- MySQL索引优化、Redis缓存策略、MQ消息队列
- **新增**：AI模型接入（异构tool_calls反序列化）、Agent框架设计 [^18]

### Python方向技能栈

**热招Python岗位技能要求**：
- FastAPI / Django / Flask 后端框架
- LangChain / LlamaIndex / RAG 架构
- Prompt工程与模型微调
- Dify / Coze 低代码Agent平台经验（外企岗位刚需）[^19]
- 量化交易方向：高频系统 + Python异步编程

### 🔥 核心结论：Agent是2026春招硬通货

> 「无Agent，无Offer」— 阿里P10毕玄：「未来没有前端、后端，也没有全栈，只有AI Agent」[^2]

- **Agent开发三件套**：RAG + 模型微调 + Agent框架 = 薪资溢价**30%-50%** [^20]
- 85%的新发AI岗位核心要求是**应用落地能力**，而非算法研究 [^20]
- 初级CRUD开发岗需求同比下降**30-40%** [^21]

### 远程/外包渠道

- **云工**：国内远程工作平台，三级严选，仅10%人才入驻 [^22]
- **程序员客栈、码上达**：2026年推荐程序员兼职平台 [^23]
- **Fiverr / Upwork**：国际远程接单（需英语能力）
- 注意：大厂外包岗位（如Java开发外包）多标注"不接受居家办公"

1. **如果你还在纯刷Java八股文 → 立刻转向**：2026面试官不再问"HashMap扩容机制"，而是问"你用大模型API做过什么辅助开发"。至少完成1个Agent/RAG落地项目放到简历上。
