### 4. ChatGPT 月活突破 10 亿，史上最快 🔥🔥

## 🧠 晚间最重要的变化

**1.** 今天下午最值得关注的是 OpenAI 的战略大转向——Brockman 接管产品后砍掉 Sora App、集中所有算力发展 Codex，这意味着 OpenAI 正式从"什么都做"转向"All in Agent 编程"，直接对标 Anthropic 的 Claude Code。这个决策的影响可能比发布一个新模型更大。

**2.** DeepSeek 首轮融资 500 亿、估值 3500-4000 亿的消息表明，这家一直以"不融资"著称的公司终于向资本敞开大门，且腾讯、宁德时代的战略参投意味着 DeepSeek 正在从纯技术公司向生态平台转型——结合 V4.1 即将发布和 Code Harness 团队的组建，DeepSeek 在编程 Agent 赛道的野心不容小觑。
