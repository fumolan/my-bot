### 1. FT深度曝光：OpenAI「Chat is dead」——ChatGPT 史上最大改版全貌

6月7日，英国《金融时报》援引十余名现任及前任员工信息，披露了 OpenAI 正在筹备的 ChatGPT 史上最大改版全貌。关键细节远超早间报道：

- **企业客户贡献 40% 营收**：200 万家企业客户，预计年底升至 50%
- **外部生态集成**：Canva、Booking.com 等合作伙伴将直接嵌入 ChatGPT
- **未来数周推出**：从网站和移动端 UI 改版开始，逐步引导用户使用编程工具、图像生成等新功能
- **战略背景**：估值 8500 亿美元，筹备年内 IPO，急需提升营收、打通盈利路径

### 2. 京东 × 腾讯联手打造 AI Agent 生态，A2A 模式覆盖主流终端

6月7日晚间，京东与腾讯宣布围绕 AI Agent 展开深度合作。京东的商品供应链与履约服务体系，将对接腾讯的生态入口资源。双方共同打造跨场景智能化服务新范式。

- **A2A（Agent to Agent）合作**：已与华为、OPPO、荣耀等主流终端厂商对接，用户可在各终端原生智能体中直接调用京东 AI Agent 完成购物
- **微信 AI 智能体**：微信正在推进 AI 智能体公开上线前的合规审批流程，14 亿用户体量使合规要求比其他产品更严格
- **闭环体验**：从意图识别到服务保障，形成完整链路

这是国内电商巨头与社交巨头在 AI Agent 领域的首次大规模联手，标志着 Agent 从"单点应用"走向"生态协同"。

### 3. 谷歌与 SpaceX 签 300 亿美元算力大单，租用 11 万颗英伟达 GPU

6月7日，SpaceX 宣布已与谷歌签署算力合作协议。2026年10月至2029年6月，谷歌每月向 SpaceX 支付 9.2 亿美元，合同总金额 300 亿美元，租用相当于 11 万颗英伟达 GPU 的算力资源。交易由 xAI 主导，主要为 Gemini Enterprise 提供过渡性算力储备。

此前 Anthropic 已与 SpaceX 签署规模更大的协议（相当于 22 万颗 GPU，月付 12.5 亿美元）。SpaceX 正成为 AI 算力市场的新巨头。

## 🟡 晚间动态

### 安全与隐私

- **Anthropic API 隐私泄露事故**：6月7日 Anthropic 服务宕机期间，有用户发现 API 返回了另一位用户的推理输出。属于严重的隔离失败，对这家以"AI安全"为招牌的公司极为讽刺。[快科技](http://finance.sina.com.cn/tech/roll/2026-06-07/doc-iniaqhwq9709265.shtml)
- **微软警告 Claude Code 存在高危漏洞**：微软威胁情报团队发现 Claude Code 的 GitHub 自动化流程存在漏洞，攻击者可通过提示词注入窃取 CI/CD 机密信息。攻击指令可藏在 HTML 注释中，GitHub 界面不可见但 AI 模型可识别。[IT之家/新浪](http://finance.sina.com.cn/tech/digi/2026-06-07/doc-iniapryu1209778.shtml)
- **Gemini 语音助理曝「Fake Context Alignment」漏洞**：SafeBreach 披露，黑客可通过 WhatsApp/短信发送特殊构造的通知，利用多语言混淆或静音超链接诱导 Gemini 执行未授权操作。谷歌已于去年 11 月通过改进内容分类器缓解。[IT之家/新浪](https://finance.sina.cn/stock/jdts/2026-06-07/detail-iniaqpen9617108.d.html)
