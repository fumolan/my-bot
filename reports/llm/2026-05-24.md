## 📊 三句话总结

1. **本周最大的信号是「Agent 时代正式开打」**：Google 用 Gemini Spark + Antigravity 2.0 构建完整 Agent 生态，阿里 Qwen3.7 以 35 小时自主执行和 SWE-bench 72.3% 证明国产模型已具备 Agent 级能力，智谱 400 tokens/s 把速度天花板推到新高度——模型竞争已从「对话质量」转向「能替你干多少活」。

2. **商业化进入硬碰硬阶段**：Anthropic 凭借 Claude Code 实现季度盈利（Q2 $109 亿营收），DeepSeek 用永久降价打价格战，豆包月活 3.45 亿却率先收费——谁能赚钱、谁能省钱，两条路径都在加速验证，免费烧钱换规模的时代结束了。

3. **对做 AI 产品的启发**：三条暗线值得关注——① AI Coding 是当前唯一跑通的规模化变现场景，Agent-first 开发工具链是兵家必争之地；② 可塑界面（动态生成 UI）可能重新定义前端架构，值得提前布局；③ 大模型定价卷到 ¥0.025 /百万 tokens，产品竞争力将越来越取决于「模型能力之外的附加值」（流程设计、数据飞轮、场景闭环），纯套壳产品的窗口正在关闭。
