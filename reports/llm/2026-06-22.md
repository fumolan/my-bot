### 1️⃣ OpenAI GPT-5.6 系列预计本周发布，Pro 版已灰度测试
- **要点**：GPT-5.6 系列涵盖 mini、标准版及 Pro 版，最可能发布窗口为 6 月 22 日至 28 日。核心升级在于从"语言模型"全面转向**可执行 Agent（executable Agent）**，上下文窗口从 100 万 token 提升至 **150 万 token**，编码、Agent 工作流及 3D 生成能力跨越式提升。定价或仅为竞品 1/3，主打低价策略抢市场。Pro 版已面向部分订阅用户灰度测试。

## 📝 3 句话总结

**1️⃣ 模型竞争进入"Agent 化"决胜阶段**——GPT-5.6、GLM-5.2、Fable 5、Kimi K2.7 Code 全部围绕 Agent 能力升级，国产模型在编程和 Agent 场景已追平甚至部分超越海外，赛道从"比参数"转向"比干活"。

**2️⃣ 人才大战取代模型大战成为新主线**——Google 48 小时连失两员核心（Shazeer→OpenAI, Jumper→Anthropic），人才流动推动价值从模型本身向"系统工程与交付能力"迁移。

**3️⃣ 国产大模型从"追赶"进入"好用"期**——GLM-5.2 开源登顶、DeepSeek V4 跑通华为昇腾、阿里 Qwen 具身智能三件套，叠加资本通道开放（科创板）和政策利好（AI+消费），国产大模型产品化落地节奏明显加速。做 AI 产品应重点关注 **Agent 工程化**（多步骤自主任务）和**国产模型 API 降本**带来的应用层机会。
