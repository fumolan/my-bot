### 4. Claude Code Agent SDK 独立额度：6 月 15 日起生效

Anthropic 宣布从 **6 月 15 日**起，所有 Claude 付费用户将获得独立的 **Agent SDK 额度**，专用于 Claude Agent SDK、`claude -p` 命令、Claude Code GitHub Actions 及基于 Agent SDK 的第三方应用。此前这些用量与 Claude Code 共享同一套额度——跑个自动化脚本可能就把 Claude Code 额度用光了。拆分后订阅额度只用于 Claude Code 交互。

加上之前宣布的 Claude Code 周限额临时提升 50%（持续至 7 月 13 日），Anthropic 在编程工具侧的补贴力度正在持续加码。

### 5. MemLens：首个大型视觉语言模型多模态长时记忆基准测试

研究团队推出 **MEMLENS** 基准，系统评估 LVLM 在多模态多轮对话中的长时记忆能力。789 个问题涵盖五大记忆能力，测试 27 个长上下文模型和 7 个记忆增强代理。核心发现：
- 长上下文模型在短对话中表现良好，但随对话延长性能下降
- 记忆代理长度稳定性好，但损失视觉保真度
- 多轮推理将多数系统性能限制在 **30% 以下**
- 80% 的题目确实需要视觉证据（图像消融验证）

结论：需要结合长上下文注意力与结构化多模态检索的混合架构。

- **来源**：arXiv / HuggingFace Daily Papers（AIHOT ⭐70）
- **链接**：<https://arxiv.org/abs/2605.14906>
- **可信度**：🟢 学术论文
