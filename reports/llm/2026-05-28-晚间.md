## 🔴 晚间重磅（下午新发布的重大消息）

### 1. 🚀 英伟达开源 Polar 框架：Codex SWE-Bench 跑分暴涨 594.74%
英伟达研究团队开源智能体强化学习框架 Polar，无需重写 Codex CLI、Claude Code、Qwen Code 等现有 agent 执行框架，在模型 API 边界接入 GRPO 训练。基于 Qwen3.5-4B 模型，Polar 将 Codex 在 SWE-Bench Verified 上 pass@1 从 3.8% 拉至 26.4%（涨 594.74%）。`prefix_merging` 技术将训练步骤从 1185 次降至 218 次，速度提升 5.39 倍，GPU 平均利用率从 20.4% 升至 87.7%。做代码 agent 的团队可以直接用，开源即拿即训。
> 📎 [IT之家](https://www.ithome.com/0/956/293.htm) · 可信度：官方论文+开源 · 🔥 AIHOT 精选 **73**

### 2. 💰 OpenRouter 完成 1.13 亿美元 B 轮融资，CapitalG 领投、英伟达跟投
AI 模型聚合平台 OpenRouter 宣布完成 1.13 亿美元 B 轮融资，由 Alphabet 旗下 CapitalG 领投，NVIDIA（NVentures）、ServiceNow、MongoDB、Snowflake、Databricks 等科技巨头旗下风投参投，a16z 和 Menlo Ventures 继续跟投。OpenRouter 每周处理 25 万亿 tokens，日均调用量超 3.5 万亿，全球用户超 800 万。本轮估值 13 亿美元，说明模型路由已从"小工具"升级为基础设施层。
> 📎 [OpenRouter 官方](https://openrouter.ai/announcements/series-b) · 可信度：官方公告 · 🔥 AIHOT 精选 **72**

### 3. ⚠️ OpenAI ChatGPT 与 API 出现高延迟故障（已修复）
5 月 27 日晚间，ChatGPT 及 API 服务出现大规模高延迟，用户提问后等待时间显著变长。OpenAI 于 5/27 22:47 确认问题，5/28 凌晨 4:06 宣布修复。状态页面仍显示 Codex 上下文压缩速度慢于预期、安卓企业版切换工作区异常等问题。这是 5 月份 OpenAI 基础设施透明度的一次压力测试。
