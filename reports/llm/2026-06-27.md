## 💡 三句话总结

1. **本周核心事件是 GPT-5.6 Sol 预览 + 美国政府要求分批发布**，标志着前沿模型发布从"公司自主"转向"政府逐客户审批"，Anthropic Fable 5 也遭出口管制——做 AI 产品和安全的团队需要重新评估合规风险等级。

2. **AI 经济的真实规模首次被厘清**：去重后年化 1750 亿美元，增长速度为移动互联网的 3 倍，且 token 降价反而刺激 12~18% 的用量增长——这意味着"更便宜"并不会让市场贬值，做大模型应用产品的窗口期依然充足。

3. **Agent 正在从开发工具渗透到全组织**：OpenAI Codex 内部占输出 token 的 99.8%、非开发者增长 137 倍；Gemini 3.5 Flash 内置 computer use、Ornith-1.0 开源、Runway Agent 2.0 打通广告全链路——Agent 不再是"编码专属"，跨职能的 Agent 产品化是未来 6 个月最重要的产品机会。
