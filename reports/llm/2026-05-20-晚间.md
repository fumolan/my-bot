### 4. 微软内部示警：GitHub 面临"生存级风险"
据 The Information 报道，微软内部已将 GitHub 定位为"existential risk"级别。Cursor、Claude Code 等 AI 编程工具正在根本性地改变开发流程——代码不再需要持续上传到托管平台。微软已要求内部团队在 6 月底前停止使用 Claude Code，统一迁移至 GitHub Copilot CLI。但开发者用脚投票：61% 同时使用过二者的开发者认为 Claude Code 更好，Claude Code 百万 Token 上下文 vs Copilot 128K，跨文件重构完成率 89% vs 60%。
