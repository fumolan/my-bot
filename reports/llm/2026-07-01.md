## 📊 今日总结

**三句话速览：**

1. **Claude Sonnet 5 发布 + 出口管制解除 + 科研工作台上线** — Anthropic 今日三连击，以低成本智能体模型和垂直场景平台（Claude Science）全面进攻，标志着 AI 行业从"谁的模型最强"转向"谁的模型最实用、最便宜、最能干活"。

2. **DeepSeek V4 正式版 7 月中旬上线 + 首创峰谷定价 + 开源 DSpark 推理框架** — 国内定价权争夺战升级，峰谷定价和开源推理优化表明 DeepSeek 正在从"价格屠夫"进化为"基础设施级玩家"，对依赖 API 的 AI 产品开发者影响深远。

3. **算力供需矛盾全面爆发** — Google 限制 Meta 使用 Gemini、黑石 300 亿美元押注日本数据中心、美国 75 个数据中心因缺电被叫停、SK 海力士赴美上市募资 294 亿美元——算力已成为比模型能力更稀缺的资源，AI 产品设计必须考虑 API 定价波动和推理成本优化。

**对我们做 AI 产品的启发：**
- 开源模型生态成熟度已到拐点，六成企业转向开源，AI 产品应优先考虑可切换模型的后端架构，避免被单一闭源模型锁定
- 峰谷定价将成为常态，AI 产品需要设计缓存策略和离线批处理能力来对冲 API 成本波动
- 智能体（Agent）能力正在从"锦上添花"变成"标配"，Sonnet 5 的 Agentic Coding 提升和 Every 的复利工程方法论都说明：AI 编程和自动化工作流是当前最确定的落地场景
